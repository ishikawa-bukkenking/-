# 助成金シミュレーター 仕様書(物件王・社内専用)

> 2026-11-16 時点の依頼プロンプトを、そのまま保存したもの。変更があれば、このファイルを更新する。

あなたは、物件王(株式会社物件王)の営業が使う、助成金シミュレーターを作る開発者です。
人材開発支援助成金「人材育成支援コース」の、助成金額の目安を計算し、見やすく表示するツールを作ってください。

# 1. 目的と、使われ方

- 使う人:物件王の社員(セールスグロース・営業)だけ。**社内専用。** 建築会社・工務店の経営者との商談で、営業が画面を共有しながら使う。お客様に、ツールのURLは渡さない
- 見せたいこと:「この研修を、◯人が受けると、助成金は合計いくら出て、実質の負担はいくらか」を、数字を入れ替えながら、その場で見せる
- 画面で、いちばん大きく見せる数字:**助成金の見込み合計**(と、実質負担額)
- 出すもの:計算結果を、1ページの書類(印刷・PDF)にして、営業が、お客様に渡せる(渡すのは書類だけ)

# 2. 絶対に守ること

1. **制度の数字は、一次資料(厚生労働省)で確認してから使う。** 民間の解説記事だけを根拠にしない。確認できなかった数字は、画面に出さず、私に報告する
2. **数字を、コードの中に直接書かない。** 制度の数字は、すべて1つのパラメータの表(JSON)に置き、各項目に、「出典(資料名・ページ・URL)」「確認した日」を付ける。次の年度に変わったら、この表を直すだけで済むようにする
3. **「概算」であることを、画面と書類のどちらにも、目立つ位置に書く。** 支給を保証しない。最終的な支給額は、労働局の審査で決まる
4. **申請手続きの案内を、物件王ができるかのように書かない。** 助成金の申請手続きは、社会保険労務士の業務。画面と書類には、「申請手続きは、社会保険労務士にご相談ください」という趣旨の注意を入れる。既存の物件王の助成金スライドに、同じ趣旨の注意書きがある場合は、その文言に合わせる(文言は、私に確認する。勝手に法的な言い回しを作らない)
5. **入力された数字を、外に送らない・保存しない。** ブラウザの中だけで計算し、通信・解析ツール・クッキー・ローカルストレージによる保存をしない(お客様の会社の数字が、入るため)
6. **費用がかからない方法で作る。** 有料のサービス・有料のライブラリ・有料のホスティングは使わない
7. **正解データ(「9」)と一致するまで、完成と言わない**
8. 分からないことは、推測で埋めず、質問する

2. 相違があれば、**一次資料を正**とする。民間の記事と違う場合は、その旨を報告する
3. 特に確認すること:
   - 加算の率と単価(賃金・資格等手当要件)
   - 計画届の期限(6か月前〜1か月前、が正しいか)
   - 1人1年度の支給回数(3回)、1事業所1年度の上限(1,000万円)
   - 助成額の端数処理(円未満の切り捨て、など)
   - 対象になる経費・ならない経費(受講料、講師謝金、教材費、施設借上費など)。自社の社員が講師になる場合の扱い
   - 賃金助成の、所定労働時間内の扱い(所定外・休日・残業の時間)
   - 事業所の人数・資本金の、中小企業の判定(3-4)
   - 令和8年8月3日以降に提出する計画届の扱いと、それ以前の経過措置

4. 一次資料にアクセスできない場合は、私に、資料(PDF)の添付を頼む。推測で数字を決めない
5. 確認が済んだ数字を、パラメータの表(2)に入れる。各項目に、出典と確認日を付ける

# 5. 計算の仕組み(第1段階:人材育成訓練)

## 5-1. 入力

画面の入力(初期値は、よくある例。すべて、あとから変えられる):

| 入力 | 内容 | 備考 |
|------|------|------|
| 企業規模 | 中小企業 / 中小企業以外 | 業種・資本金・従業員数から、自動判定もできる(3-4。確認できた場合のみ) |
| 受講者の区分と人数 | 正規雇用労働者等 ◯人 / 有期契約労働者等 ◯人 | 区分ごとに率が違う |
| 訓練の形式 | 通学制・同時双方向型 / eラーニング・通信制 | eラーニングは、賃金助成なし、限度額の区分は固定(3-2) |
| 訓練時間(1人あたり) | OFF-JTの時間 | 10時間未満は、対象外と表示 |
| 所定労働時間内の割合 | 訓練時間のうち、所定内に受講する割合 | 賃金助成の対象は、所定内のみ |
| 対象経費(1人あたり) | 受講料・講師謝金・教材費など(税抜) | 消費税の扱いは、一次資料で確認 |
| 賃金要件等 | 満たす見込み / 満たさない | 加算の有無 |
| 実訓練時間の見込み | 予定時間のうち、実際に受講する割合 | 通学型は、80%未満だと対象外の警告 |

## 5-2. 計算(1人あたり。区分ごとに)

```
経費助成(基本)   = min( 対象経費 × 基本の経費助成率 , 限度額[訓練時間の区分] )
賃金助成(基本)   = 賃金助成単価 × min( 所定内の実訓練時間 , 1,200 )   ※eラーニング・通信制は0
経費助成(加算込み)= min( 対象経費 × 加算後の経費助成率 , 限度額[訓練時間の区分] )
賃金助成(加算込み)= 加算後の賃金助成単価 × min( 所定内の実訓練時間 , 1,200 )
基本分 = 経費助成(基本)+ 賃金助成(基本)
加算分 = (経費助成(加算込み)+ 賃金助成(加算込み))− 基本分
```

合計は、人数をかけて、区分ごとに足す。そのうえで:

- **1事業所1年度あたりの上限(1,000万円)**を超える場合は、上限で切り、「上限に達しています」と表示する
- **実質負担額 = 対象経費の合計 − 経費助成の合計**(賃金助成は、会社が支払った賃金への助成なので、負担額からは引かず、別に「賃金助成(受講中の人件費への助成)」として表示する。扱いは、私に確認する)
- 端数は、一次資料の決まりに従う(確認できるまでは、円未満の切り捨て)

## 5-3. 注意の表示(計算に出ない条件。チェックリストとして、結果の近くに出す)

- 計画届を、訓練開始の1か月前までに出すこと(日付を入れると、締切日を自動表示:「計画届:◯月◯日まで(原則、開始6か月前〜1か月前)」「支給申請:◯月◯日まで(終了日の翌日から2か月以内)」)
- 実訓練時間の8割以上の受講が必要
- 事業主の要件(雇用保険適用事業主、職業能力開発推進者の選任、事業内職業能力開発計画の策定など。一次資料で、要件の一覧を確認して出す)
- 加算分は、別の申請になること
- 1人1年度3回までの回数、事業所の年間上限
- 最終の支給額は、労働局の審査で決まること

# 6. 画面

- **1画面・1ページのツール。** 左(スマホでは上)に入力、右(下)に結果
- 結果の見せ方:
  1. いちばん大きく:**助成金の見込み合計**(基本分)。その下に、「加算を満たす場合:+◯円(別途申請)」
  2. 次に:内訳(経費助成 / 賃金助成)、1人あたりの金額、実質負担額
  3. 計算の途中(どの数字に、どの率をかけて、限度額で止まったか)を、「計算の内訳を見る」で開ける。**経営者が、「なぜこの金額か」を、自分で追える**ことが大事
  4. 注意のチェックリスト(5-3)
- 数字を変えると、結果がすぐに変わる(送信ボタンは付けない)
- 「条件を変えて比べる」:加算なし / あり を、並べて見られる
- 「1ページの書類にする」:印刷・PDF用の見た目(A4・1ページ)。会社名の入力欄(任意)、日付、概算の注意、出典と確認日、物件王のロゴを入れる

# 7. デザイン

物件王のロゴの色と、BCB(物件王のデザインの知見)の方針で作る。BCBのスキルが使える環境なら、使ってよい。

- 色:ロゴのティール `#05968C`、ロゴの文字の濃いグレー `#374141`(純黒は使わない)。白地の小さい文字には、`#05968C` は明るさが足りない(白との差3.65:1。基準4.5:1)ので、文字・ボタンには、少し濃いティール(例 `#04746D`。白との差5.64:1)を使う。値は、実際に計算して確かめる
- 色の割合:背景・面 70〜90%(白と、ごく薄いグレー)/ メイン(ティール)10〜20% / アクセント 5〜10%(1色だけ。いちばん大事な操作、または、結果の強調にだけ使う。ロゴに無い色なので、色相の違う2〜3案を、モックで見せて、私が選ぶ)
- フラット。影をつけない。区切りは、細いグレーの線。角丸は、決まった4段階を、全体で同じ役割に同じ値で使う
- 大きな数字(助成金の見込み合計)が、画面でいちばん大きい文字。数字は右揃え、通貨は「¥1,234,000」
- 見出しは日本語。飾りに、小さな英語を添えてよい
- 同じ役割は、同じ見た目(ボタン、入力欄、カード)。AIが作ったような、どこでも見る見た目(派手なグラデーション、ぼかし、過剰なアイコン)は避ける
- 画面共有で読める文字の大きさ(本文16px以上、結果は大きく)。スマホでも崩れない
- 入力欄に、見えるラベルを付ける(単位・説明つき)。エラーは、責めずに、直し方を書く(例:「訓練時間は10時間以上で入力してください。10時間未満は、この助成金の対象外です」)
- キーボードだけで操作でき、フォーカスが見える

# 8. 技術(費用ゼロ)

- **1つのHTMLファイル**(CSS・JavaScriptを内に持つ)。ライブラリは、使わない(計算は簡単なので)。ロゴは、base64で埋め込む
- パラメータの表(JSON)は、同じHTMLの中に、`<script type="application/json">` として入れる(別ファイルにすると、ファイルを開くだけでは動かないため)。表の項目には、出典と確認日を持たせる
- **公開の場所:社内専用(決定)。** 次の方法を、費用・手間・安全性の表で比べて、おすすめを出す。**URLを知っていれば誰でも見られる状態にしない**(静的ホスティングの無料枠は、多くの場合、パスワードや社内限定の設定が有料。損益計算書ツールのnetlifyも、同様に公開されていないか確認する)
  - A(私の見立て・おすすめ):**Google Apps Scriptのウェブアプリ**(HtmlService)。「組織内のユーザーのみ」で公開すれば、@bukkenking.comのアカウントだけが開ける。無料。計算は、ブラウザの中だけで行い、サーバー側には、入力を送らない・保存しない。HtmlServiceの枠の中で、印刷・PDF(window.print)が動くかを、最初に確かめる
  - B:HTMLファイルを、社内の共有フォルダで配り、各自のパソコンで開く(ホスティング不要。更新したら、配り直す手間がある。年度ごとの数字の更新が、全員に届く仕組みを考える)
  - C:ほかの無料の方法(あれば。費用がかかるものは、提案だけして、使わない)
  どれにするかは、表を見て、私が決める
- 計算は、ブラウザの中だけ。外へ送らない。保存しない(2の5)
- コードは、「計算(関数)」「パラメータ」「画面」を分ける。計算の関数は、画面なしで、テストできるようにする

# 9. 正解データと、検証

No.1は、民間の解説記事の計算例(賃金800円×30時間=24,000円、経費10万円×45%=45,000円、合計69,000円)と同じ。他は、私が、3の数字から手で計算した値。**一次資料で数字が違えば、期待値も、一次資料から計算し直し、その差を、私に報告する。**

## 9-2. 検証

2. 境界の確認:訓練時間 9 / 10 / 99 / 100 / 199 / 200時間(限度額の区分が切り替わる位置)、賃金助成の上限時間(1,200時間)、実訓練時間が79% / 80%、年間上限の前後
