# 事業計画書Excel 修正点のご確認のお願い

## 1. 概要
不動産仲介の新規出店向け「事業計画書」(記入例入り・12シート。記入例の数字は、後からいただいた260708版に合わせています。整形版・テンプレート版では社名を仮の「株式会社〇〇」にしています)について、「見やすく・使いやすく」するための整形と、他社でも使い回せる「テンプレート版」の作成を行いました。内容のご確認をお願いします。

**最優先で守ったこと: 入力内容を変えない**
- 元のExcelは上書きしていません(別ファイルで作成しています)。
- 元の12シートの**数式2,259個はすべて元と同一**です。後から追加した3シート(給与整合性・インセンティブ検討・能力判定)の数式359個も、取り込み元と同一です。**セルの値(約30万セル)も、社名(株式会社〇〇、ご指示による変更)の1セルと、記入例を260708版に合わせた32セルを除いて全件同一**です。
- シート名・並び順・セルの位置・結合セル・データ入力規則・条件付き書式・図形・画像・グラフは変えていません。
- LibreOfficeで再計算し、260708版(式が異なる4セルだけ260804版の式にしたもの)の計算結果と2,618件すべて一致することを確認しました。

## 3. 元のExcelからの修正点

### 3-1. 見た目(値・数式は変えていません)
- **入力セルと数式セルの見分け**: 色を「中身が入力か数式か」で統一しました。
  - 入力セル: 薄い水色の背景＋青文字
  - 前提(想定値)のセル: 薄いグレーの背景＋青文字
  - 数式セル(自動計算): 背景なし＋黒文字
  - 計算用の作業領域(PL・簡易PLの右側など): グレーの背景＋グレー文字(非表示にはしていません)
  - 元の「水色」は入力のほか、ラベルや数式にも使われていました。PLの水色の数式セル548個は、数式用の見た目に統一しました。
- **配色**: 物件王HPのグリーン(#07968C)を基調に、見出しは緑の背景＋白文字、小計・合計は薄い緑にそろえました。
- **数字の表示**: 0は「-」で表示します(値は0のまま)。小数の誤差(84000.00000000001など)は表示形式で見えなくしました。円・件・世帯・%などの単位表示は元のままです。
- **文字**: フォントを BIZ UDPゴシック に統一し(店舗内装のArialなども)、9pt未満の文字は9ptに引き上げました(PLの6pt、事業検討・決定事項の8pt)。
- **罫線**: 細線・同じ色にそろえ、結合セルで欠けていた罫線を補いました。

### 3-2. 画面の使い勝手
- 各シートの先頭を A1 にそろえ、見やすい倍率にしました。選択セルは各シートの最初の入力セルです。
- 目盛線を非表示にしました。PLには見出し行・列の固定(ウィンドウ枠の固定)を入れました。
- シートの見出し(タブ)を色分けしました(入力系=青、計算・確認系=グレー、提出・印刷系=緑)。
- 全体フロー・研修詳細は、図形がマス目に固定されているため、行の高さ・列の幅を変えていません。

### 3-3. 印刷
- 用紙は元のまま(A3のシートはA3、A4のシートはA4)です。
- すべてのシートを「横幅1ページ」に収めました。ヘッダーフッターに、シート名とページ番号を入れました。
- 元はPLなどが4ページに分かれて印刷されていましたが、1ページに収まるようになりました(全体で32ページ→13ページ。ほかに「まとめ」3ページと、取り込んだ3シートで3ページ)。
- **決定事項(署名・捺印する書類)**は、署名欄まで含めて**A4・1ページ**に収まります(元は4ページに分断され、署名欄が別ページでした)。文面は変えていません。
- 印刷範囲が未設定だった4シート(社名・全体フロー・店舗内装・ターゲットエリア)に、作業領域を含まない印刷範囲を設定しました。

### 3-4. 追加したシート
- **給与整合性・インセンティブ検討・能力判定**(整形版・テンプレート版の両方): 元のデータ(260708版)にあった3つのタブを、「PL(2年目以降)」と「決定事項」の間に取り込みました。値・数式は元のままで、ほかのシートと同じ見た目・印刷設定にそろえています。給与整合性とインセンティブ検討は、目標設定・事業検討・PLと連動して計算されます。テンプレート版では、各人の評価点や入社日などの入力を空にしてあります。
- **まとめ**(整形版・テンプレート版の両方): 入力した内容のまとめと、グラフを1枚にまとめたシートです。他のシートを参照する数式だけで、入力は不要です。入力すると自動で更新されます。
  - グラフ用の補助表は同じシートの O〜U 列にありますが、非表示にしてあります(必要なら「再表示」で見られます)。
  - 内容は次のとおりです。会社名・免許・対象エリア(入力した数に応じて自動で増減)・世帯数・目標・店舗条件のまとめ、黒字化のタイミング(累計グラフ)、損益分岐点と必要契約数、簡易P&L、月次推移の表、建築事業の利益イメージ。
- **使い方**(テンプレート版のみ): 色の意味、シートの一覧と入力する順番、入力時の注意、数式に直書きされている前提(定数)の一覧を載せています。

### 3-5. テンプレート版での扱い
- 会社固有の入力は**空にしました**(136セル。うち能力判定の評価点100セルは、元の空欄表記=全角スペースに戻しています)。社名は仮の「株式会社〇〇」を初期値として入れてあります(書き換えて使います)。対象エリア名・世帯数・物件数・金額、免許の有無、目標利益、事業検討の確定件数・採用費・店舗賃料・減価償却区分・店舗改装費・看板費など。三ツ星不動産の文字列は、ファイル内部からも消してあります。
- 想定値・前提は**初期値として残しました**。CPC、歩留り、過去事例の経費、物件王の加盟金・会費、建築シナジーの単価・利益率、免許費用、店舗内装の面積など。
- 目標設定の対応事業(□/■)は、□(未選択)にしてあります。PLの入力欄は元から0のままです。
- **シート保護**: 全シートに保護をかけました(パスワードなし)。入力セルと前提セルだけ書き込めます。数式セルは書き換えできません。解除は「校閲」→「シート保護の解除」です。

## 4. ご確認いただきたい点(数式は修正していません)
数式は変更しない方針のため、気づいた点は直さずに記載しています。意図どおりかどうかをご確認ください。

- [ ] **手数料/件が2つの値になっています。** 目標設定!J16 は 432,932円、事業検討!E4 は 432,000円(千円未満を切り捨て)です。どちらを正とするか。
- [ ] **事業検討!O43 の条件が成立しません。** `=IF(L51=5000000,0,L43)` ですが、加盟金(L51)は4,500,000円です。500万円を想定した書き方に見えます。
- [ ] **事業検討!L54(店舗改装費用)が空欄です。** 減価償却(C49)と店舗組成費の合計に影響します。記入例では未入力です。
- [ ] **事業検討!W36 の結果が常に0です。** `=X37*Z3` ですが、Z3 は空です。不要な式の可能性があります。
- [ ] **簡易PLの件数が手入力です。** D7:D9(2/1/1)と I7(6)は、PLの件数と連動していません。連動させるべきか。
- [ ] **PL(2年目以降)の行6などで、数式のセルと定数0が混在しています。** 入力の意図か。
- [ ] **簡易PLの内部差**: 簡易PLの表の1年目営業損益(−630,468円)と、グラフ側の12ヶ月累計(−488,100円)に差があります(グラフ側は1ヶ月目の販売管理費に2ヶ月目の値を使っています)。「まとめ」は簡易PLのグラフと同じ集計(開業時の初期費用を含まない)にしています。
- [ ] **記入例は260708版に合わせました(ターゲットエリア・目標設定・事業検討の32セル)。** 年間営業利益目標が0、店舗賃料・採用費などが空欄、ターゲットエリアが1つになります。式・ラベルは260804版のままで、社名は「株式会社〇〇」のままです。
- [ ] 260708版の「目標設定」は、手数料の端数処理の数式(AB24:AB26、G25)が260804版と異なっていました(260804版が新しい形)。今回は260804版の式のままなので、端数がずれる可能性があります。
- [ ] **印刷範囲の外し方**: 目標設定は A〜AD列までで、AF〜AO列(年間契約数・手数料合計・営業利益)は範囲外です。事業検討・簡易PL・PLも作業領域を範囲外にしています。意図的な外し方と判断し、変更していません。
- [ ] **テンプレートで「前提」として残した値の範囲**(加盟金450万円・会費20万円/月・免許費用・面積など)は適切か。
- [ ] **テンプレート版で入力が空のとき**、割り算を含む数式が `#DIV/0!` を表示します(763セル。`#DIV/0!` 757、`#N/A` 6。起点は29セルで、ターゲットエリア9、給与整合性19、インセンティブ検討1)。給与整合性の `#N/A` は、元の式が空の行を除外するために意図的に返すもので、元のサンプルでも16個出ています。入力を進めると消えます。元のサンプルでも、ターゲットエリアの8セルは元から `#DIV/0!` です。エラー表示を隠す案が必要でしたらご連絡ください(隠す案の動作は確認済みです)。
- [ ] 数式に直書きされている定数(0.548231、14%、×30,000、3%+6、110% など、51パターン・274セル)の一覧は、テンプレート版の「使い方」シートにあります。

## 5. 確認方法とお願い
1. 整形版を開き、元のExcelと見比べてください。数字(特に営業損益・損益分岐点)が元と同じことをご確認ください。
2. 「まとめ」シートの内容と見た目をご確認ください。
3. テンプレート版は、実際に新しい会社の数字を入力して、各シート・「まとめ」に反映されることをご確認ください。
4. **注意**: Excel実機での動作(「修復しますか?」の警告が出ないか、フォントBIZ UDPゴシックでの見た目)は、まだ確認できていません。お手元のExcelで開いて、気になる点があればご連絡ください。
