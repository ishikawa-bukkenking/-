## おすすめ

**A(Google Apps Script・組織内のみ)。** 理由は次の3つです。
1. 費用がかからず、新しい契約もアカウントも要りません。
2. 会社の Google アカウントで入るので、社外には開けません。退職者の管理も、既存のやり方で済みます。
3. 年1回の更新は、スクリプトの貼り替えだけです。URLは変わりません。

**条件:最初に、印刷(PDF)が、Apps Script の枠の中で動くことを確かめる。**
動かない場合は、次のどちらかにします。
- 画面の「書類にする」を、「別のタブで、書類を開く」に変える。
- C(Cloudflare Access)に切り替える。

**社外の人(会社のドメインでないアカウント)にも使わせたい場合は、C(または E)にします。** A は、ドメインの外の人を、個別に許可できません。

**D は、使いません。** 無料のままだと、URLを知っている人は、誰でも開けるためです。
このリポジトリの `netlify.toml` は、別のサイト(町中華「大門」)のものなので、このツールには使いません。
別の損益計算書ツールの Netlify が、非公開になっているかは、こちらでは確かめられません(URLを知らないため)。確かめる場合は、ログアウトした状態(またはシークレットウィンドウ)で、そのURLを開いてください。開ければ、公開になっています。

## Apps Script での公開手順(A)

最初に、印刷の動作確認をします。

1. [script.google.com](https://script.google.com) で、会社のアカウントで「新しいプロジェクト」を作る。名前は「助成金シミュレーター」。
2. 左の「プロジェクトの設定」で、「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェックを入れる。
3. `subsidy-simulator/gas/` の、次の4つを、エディタに貼る。
   - `Code.gs` → 既存の `コード.gs` に貼る
   - `appsscript.json` → 全部置き換える
   - `test.html` → 「+」→「HTML」で、名前を `test` にして貼る
   - `index.html` → 同じく、名前を `index` にして貼る
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」→ 次のように設定する。
   - 次のユーザーとして実行: **ウェブアプリケーションにアクセスしているユーザー**
   - アクセスできるユーザー: **@bukkenking.com 内の全員**(組織内のみ)
5. 出てきた URL の末尾に `?page=test` を付けて開く。3つのボタンを順に押し、結果を、お知らせください。
   - ①の印刷の画面が出て、PDFに保存できるか。
   - ②の別タブで、印刷できるか。
   - ③のファイルが保存されるか。
6. 問題がなければ、同じURL(`?page=test` なし)が、ツール本体です。

## 公開前の確認(ステップ4・検証7b)

次の3つを、実際に試してください(こちらからは、できません)。

- [ ] 会社のアカウントで、ツールが開く。
- [ ] **ログアウトした状態**(シークレットウィンドウ)で、URLを開くと、ログイン画面になり、ツールは見えない。
- [ ] **会社以外の Google アカウント**(個人の Gmail など)でログインしてURLを開くと、アクセスできない旨が出て、ツールもパラメータの表(出典・確認日)も見えない。

## 更新の担当

Apps Script の、スクリプトの編集権限を持つ人が、更新を担当します。担当者を決めて、その人を、プロジェクトの編集者に入れてください(1人だけが持つと、退職時に止まるので、2人以上)。
